# Design

## Context

用户选择产品而非界面，配置该产品所有已核实的本机入口。产品身份来自 catalog；宿主路径与结构来自当前章节。消费者查询和 MCP 仍只读，init 是独立的显式配置写入命令。

## Decisions

- 移植 ResearchSpec 的 searchable-multi-select：搜索栏、默认 15 项滚动窗口、光标和选中标记、快捷键、过滤后保留选择、完成摘要。用可注入提示接口连接产品选择、作用域和确认；默认不预选。
- `--tools` 跳过选择 TUI，默认项目级；`--global` 选择全局。项目根是 cwd。全部不支持项目级则禁用项目级；部分不支持则在选择说明、警告和计划中列出跳过产品。
- TUI 和参数模式共享 prepare/apply 服务。始终先展示计划，确认默认否；仅参数模式接受 `--yes/-y`。非 TTY 要求显式产品与跳过确认。JSON 模式提示与计划走 stderr。
- JSONC、TOML 和 YAML 使用保留格式的成熟编辑器。共享文件先合并候选编辑。同名配置相同则不写，不同则计划更新；其他服务器和设置保留。
- 确认前完成全部解析、生成和可写性预检，不产生文件。任一异常阻止整轮写入；已知不支持入口仅跳过。确认后核对基线、备份并替换，失败恢复本轮写入，保护并发修改。
- Amazon Q 只编辑已有 agent JSON；Bob 全局与 Rovo Dev 默认路径有歧义时跳过，Rovo Dev 使用显式 mcpConfigPath。IDE 入口只写已定位的配置。
- 启动配置为 `npx -y agent-harness-wiki mcp`，显式消费者运行选项随配置传递。init 不初始化在线服务、不执行宿主或下载知识。
- 构建生成轻量 catalog 身份投影并纳入消费者包。依赖由 pnpm 精确锁定，公开版本 1.1.0；配置文档默认最新 npm dist-tag。

## Risks and Validation

配置入口的版本与信任要求随上游变化；适配器保留来源及生效提示。多文件替换不是系统级事务，错误时通过备份尽力恢复并报告剩余文件。测试覆盖用户可见行为与保留配置，不固定整段提示或 ANSI 输出。实际 tarball 在隔离 HOME、含空格路径和受控 npm registry 下验收，跨平台只报告实际运行结果。
