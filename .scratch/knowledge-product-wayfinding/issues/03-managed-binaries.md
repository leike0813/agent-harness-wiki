# 确定备用二进制的职责

Type: grilling
Status: resolved
Parent: [重新确定知识库交付与维护契约](../map.md)

## Question

真实二进制在知识库中承担什么职责，保存在哪里，隔离环境需要达到什么最低可用性？

## Resolution

- 为每个已收录产品在仓库受管目录保留一份最新版本的二进制，并建立可复用的隔离运行环境，以备以后针对具体问题测试。
- 二进制本体放在 Git 忽略的本地受管目录；Git 只记录版本、身份和取得方式。
- 建立环境时允许不调用付费服务的最小启动检查，确认环境可用；检查结果不作为主题能力的知识依据。
- 二进制运行不作为日常知识来源或知识发布门槛。

这些选择来自本轮对话中用户对 Q9、Q12 的答复与采纳。如何界定“最新”、替换旧制品及维护隔离环境留待后续议题。
