# 确定 MCP 工具参数与返回契约

Type: prototype
Status: resolved
Assignee: codex
Parent: [重新确定知识库交付与维护契约](../map.md)
Blocked by: [细化七类主题的调查问题与章节内容](04-topic-contract.md)

## Question

在已确定的五个候选工具 `list_harnesses`、`get_topic`、`search_knowledge`、`compare_topics`、`get_source` 上，逐一确认输入参数、默认值、整章/小节选择、版本请求、分页、错误与未知项表达，以及返回的正文、结构化索引、来源引用和发布身份。用真实用户提问模拟 Agent 连续调用后确定契约。

## Discussion

- 首轮连续调用样例见[MCP 连续调用草样](../mcp-contract-prototype.md)；尚未确认字段和默认值。
- 用户确认：`get_topic` 默认按当前发布的固定来源范围读取；无法证明与安装版本对应时返回 `not_verified` 且不附正文；`section_id` 采用页面稳定锚点，调查问题通过 `question_ids` 索引；整章超限时明确返回超限结果与小节索引，供 Agent 分节读取。
- 用户确认：比较只返回共同问题的状态、来源和小节定位；搜索不接收安装版本筛选，返回正文片段与来源范围；来源工具只读发布内的快照身份、官方链接、精确定位和短摘录；局部未知、不适用、冲突在问题上标记，已有主题顶层为 `ok`，安装版本无证据时顶层为 `not_verified`。
- 用户调整版本方向：请求应能模糊匹配最近的版本；省略版本表示最新。相应的“最新”和“最近”选择规则、近似结果的适用性表达仍在讨论。用户质疑形态、平台和条件的独立输入必要性；草案现仅保留章节正文中的适用条件，不要求这些工具参数。
- 用户确认：“最新”是当前知识发布的最新调查章节，不等于最新软件发行版；近似版本只向前找不晚于请求版本的可信软件版本映射，并在响应中标明请求版本未验证。无可信软件版本映射时提供固定来源章节，但不编造软件版本。
- 用户确认：当前发布的只读索引须包含仍可查询的历史章节，使固定在一个发布上的 MCP 进程能够匹配历史版本；存储形式留给知识模型议题。

## Resolution comment

确认五个只读工具：`list_harnesses`、`get_topic`、`search_knowledge`、`compare_topics`、`get_source`。`get_topic` 返回完整主题或稳定小节的正文，问题编号作索引；比较只对齐问题状态、小节和来源，搜索返回可回读的小节定位，来源工具只读发布内的固定来源身份、官方链接、定位与短摘录。每个响应标识固定的知识发布，不允许单次切换发布或读取归档原件。输入不另设形态、平台和条件过滤；章节正文解释其适用范围。

省略软件版本读取当前发布中的最新调查章节。指定版本优先精确映射或同前缀已知版本，否则只向前找不晚于请求版本的最近可信映射；无软件版本映射时返回固定来源章节作为 `source_only`。近似和来源结果必须给请求版本、实际匹配版本或 `null`，以及未验证的适用性标记，不能冒充请求版本已验证。当前发布索引仍可查询的历史章节，保证固定发布的 MCP 进程能完成最近版本选择，不拼接不同版本形成虚构正文。

局部未知、不适用和冲突保留在调查问题上；技术错误与正常业务状态分开。列表和搜索使用绑定发布及查询条件的 cursor；整章超限返回小节索引，单个小节须可完整读取。具体输入、默认值、输出、大小边界与五工具连续调用样例见[MCP 工具契约与连续调用样例](../mcp-contract-prototype.md)。现有 PRD 与实现的旧工具契约由后续迁移议题处理。
