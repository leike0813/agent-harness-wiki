# 确定 Agent 调查、复核与发布政策

Type: grilling
Status: resolved
Parent: [重新确定知识库交付与维护契约](../map.md)

## Question

源码和官方文档调查结论如何进入正式知识，谁复核，以及一次手动增量更新如何结束？

## Resolution

- 开源项目跟踪仓库并分析源码，官方文档可以辅助；闭源项目调查固定的官方文档快照。二进制运行不是日常知识来源，也不是知识验收条件。
- 调查 Agent 的结论可以直接采纳。常规调查由执行 Agent 引用来源、自检并发布；有矛盾或高影响改动时可让另一 Agent 复核。人审不构成发布门禁，用户发现问题后可以随时要求修订。
- 上游检查由人手动发起；一次调用内可以自动完成变化定位、受影响章节修订、按需复核、结构与来源检查以及新本地发布。失败时保留旧发布和调查记录。
- MCP 进程固定使用启动时的发布；切换本地发布后重启进程才读取新版。

这些选择来自本轮对话中用户对 Q3、Q7、Q8 的答复与采纳。具体来源冲突表达、更新粒度和校验条件留待后续议题。
