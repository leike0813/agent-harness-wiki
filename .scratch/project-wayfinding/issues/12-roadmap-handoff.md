## Question

如何把已定决策落实为覆盖 M0–M2 的可实施规格、依赖关系与验收顺序，并同步 PRD 和必要的项目约束？M0 已明确的实施链路如何作为起点，M1 以真实知识接入和受管制品可运行为重点、M2 调查改由项目 Skill 执行以及原 M3 的跨平台和远程 MCP 要求移除后，各阶段如何调整？

## Resolution

实施路线见仓库内的 [docs/roadmap.md](../../../docs/roadmap.md)。用户接受：M1 对首批三个可执行目标都尝试建立独立运行环境，至少一个精确制品完成真实启动验收；其余目标若受客观条件阻塞则保留具体原因，不宣称可运行。路线列明 M0–M2 交付、依赖、验收、拟修改文件与 PRD 修订清单。当前只完成规划文档，尚未实施 M0–M2 功能或同步长篇 PRD 条目。

后续[界定 harness catalog 的分期与完成标准](14-harness-catalog-phases.md)将首批范围扩为五个；[PRD](../../../docs/PRD.md) 与 `AGENTS.md` 已同步路线。本议题正文保留当时交接状态。
