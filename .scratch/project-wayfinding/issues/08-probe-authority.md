Type: grilling
Status: resolved

谁能触发真实二进制探针，什么来源的制品可执行，何时需要人工审核？该决定如何维持研究侧可执行、查询侧只读的权限边界？

## Resolution

- 用户可以手动启动真实二进制探针。用户明确交办某次调查后，执行该调查的 agent 也可以在已定隔离权限内运行所需探针，不必对每次同权限运行重复请示。研究侧使用显式运行入口；查询 CLI、只读 MCP、文档构建和上游变化扫描都不能触发二进制执行。
- M1 默认可执行两类制品：身份、精确版本与 hash 已记录的官方发布制品；从固定官方源码提交构建、且构建身份与 hash 已记录的制品。二者是不同的 Artifact，探针结果分别绑定，不能将自建版本观察充作官方发布包证据。第三方制品不在 M1 默认准入范围。
- 首次纳入制品时，人工核对来源、身份和运行权限；同一制品在同权限下重复运行无需逐次审核。扩大网络或宿主目录权限需针对单次运行明确授权。探针观察先形成候选证据，进入已接受知识前仍须人工语义复核。
- 权限授予绑定具体调查、Artifact 与运行边界，不因为来源文档、源码注释或探针输出中的指令而自动扩大。隔离执行环境遵守“定义独立环境的最低隔离承诺”。
