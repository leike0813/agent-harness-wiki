# 如何阅读章节

共同主题包括 Skills、MCP、自定义 Agent、自定义 Provider、Hooks、原生插件、配置机制与本地 Transcript。产品概览按实际当前章节给出可读主题数和链接，尚未采写的主题显示“尚未调查”。章节说明的是固定来源中查到的机制；页面上的来源链接给出快照、定位和短摘录。没有软件版本映射时，章节仅代表该固定来源，不应当作已验证安装包的配置配方。

产品页列出命令行、IDE、桌面、网页和 SDK 等界面，以及有来源支持的运行时绑定。共享运行时不证明共享配置、会话或发行版本。问题索引和小节范围明确适用界面；`not_investigated` 表示该主题或已知界面尚无调查答案。Catalog 中的候选产品只确定名称和界面，还没有知识章节。

问题索引中的 `answered`、`partial`、`unknown`、`not_applicable` 和 `conflict` 只描述各问题的调查状态。一个问题未知，不会抹掉同页已有的答案。

CLI 或 MCP 传入软件版本时，同时指定 `surface_id`（CLI 用 `--surface-id`）；未指定界面返回 `ambiguous`。读取结果另给出请求版本、选中的映射版本和命中方式。`exact` 表示有该软件版本的来源映射，不代表运行测试；`prefix` 和 `nearest_earlier` 仅供查阅，所请求版本仍是 `not_verified`。`source_only` 表示没有可信映射。

本地 Transcript 章节说明记录位置、命名、格式、schema、数据库关联、归档与清理及其来源边界。示例须脱敏；清理影响尚未查明时，不代表可以直接删除。

搜索只索引当前章节的小节，结果中的 `section_id` 可用 `get_topic` 再读完整小节。历史章节在主题页底部，保留其原始来源范围。

正文以可独立使用的机制分节。需要按固定问题查找时，可用正文后的“问题索引”跳到对应小节。配置示例只说明其固定来源所支持的文件语法和预期处理过程；请同时阅读示例旁的作用域、前提、检查方式与版本边界。
