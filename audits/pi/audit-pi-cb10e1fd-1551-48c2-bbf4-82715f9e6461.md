## Triage rationale

`thinkingLevelMap` is a first-party model metadata field described in `providers-metadata`; the published
v7 text ("`xhigh` 与 `max` 视为不支持") is exactly the description upstream corrected, while
`getSupportedThinkingLevels()` (unchanged in this diff) keeps `xhigh`/`max` only when mapped. That makes the
published statement wrong for the new fixed source, so a new edition is required. `pi-classifier` extends the
`providers-protocol` classifier API enumeration that the chapter lists from `types.ts`.
