## 语义判断

### `packages/coding-agent/src/core/settings-manager.ts`（304 行，净减 190）

逐块比对结论是纯重构，不是功能删除：

- 删掉的内容是 `CompactionSettings`、`RetrySettings`、`TerminalSettings`、`Settings` 等接口声明，
  搬到新的 `settings-schema.ts`（TypeBox 定义），并由 `settings-manager.ts` 以 `export type` 原样转出。
- 默认字面量集中到新的 `settings-defaults.ts` 的 `SETTINGS_DEFAULTS`，34 个 hunk 中绝大多数是
  `?? 字面量` 换成 `?? SETTINGS_DEFAULTS.x`，取值逐一比对未变。
- 读取路径与合并逻辑无改动：`isMergeableObject` 之后到类定义之间没有 hunk，配置加载与作用域合并代码未变。
- `Settings` 键集合逐个比对：新增 `$schema`、`queueMode`、`websockets`（后两项本就在迁移代码里，
  现在同时进入模式并标 `deprecated`），无删除项。
- 唯一与默认值无关的新增是 `clearOnShrink` 分支读取 `PI_CLEAR_ON_SHRINK` 环境变量。

对 configuration 的实质影响因此只有三处：默认值的存放位置、已弃用键的标记方式、随包发布的 JSON Schema。

### `packages/ai/src/types.ts`（413 行）

也是搬迁：provider 兼容与模型元数据类型移到 `packages/ai/src/providers/compat-schema.ts` 与
`model-schema.ts`，再从 `types.ts` 原样转出，对外导入路径不变。逐接口比对
`OpenAICompletionsCompat`、`OpenAIResponsesCompat`、`AnthropicMessagesCompat`、`BedrockCompat`、
`MistralConversationsCompat` 字段无增减，只多出 `description` 与 `additionalProperties: true`。
新增的实质字段是 `AssistantMessage`／`ToolResult` 的 `durationMs`、`ClassifierContext.images`、
`KnownClassifierApi` 的 `openai-decisions`，以及 `docs/providers.md` 的 Azure provider ID 改名
（`azure-openai-responses` → `azure`，api id 不变）。
