## 4. mcp v2 改了什么

已发布 v1 把预置 server 的入口写成 "MCP Servers for Replit Agent 区域"。当前
`build/connect-via-mcp.md` 描述的是：在 Integrations 页对目标 server 点 **Sign in** 完成该服务
的 OAuth；`features/mcp/overview.md` 的每个 server 支持一键安装，装完 Agent 自动加载工具；
自定义 server 保存后连接出现在 **MCP Servers** 面板。v2 据此改写 `mcp.entry` 的第一条入口，
并把 `mcp.diagnostics` 的"配置是否被读取"从旧区块名改为 **MCP Servers** 面板。

v2 使用的引用全部是既有记录：`ref-replit-mcp-connect-prelisted`、`ref-replit-mcp-list`、
`ref-replit-mcp-connect-custom`、`ref-replit-conn-scope`。这四条摘录的文字在当前页面里仍逐字
存在，因此修订有可用证据，不需要新的 snapshot。
