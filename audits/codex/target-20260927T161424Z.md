### 后续 Git 审计不能填补首轮缺口

已复核的[源码审计](audit-codex-cli-079462d0-b4be-4793-aa9a-ee283e0ac4fe.yaml)确认 Git 从 `67a7096…` 前进到 `41f9084…`，所查差异是两处日志内容变化；四份重新登记的文档内容 hash 与旧快照一致，npm `0.157.1` 的 integrity 也未变化。该结论只针对差异和来源身份。没有发行构建映射，就不能用新 commit 为旧 npm 包背书，也不能从“两处代码未改配置路径”推断完整配置机制已经验证。七份额外的 `source-tree` Coverage 另属该审计，不计入下表的七份 npm 调查。
