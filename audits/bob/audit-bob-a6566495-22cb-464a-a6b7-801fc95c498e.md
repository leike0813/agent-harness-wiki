# Bob Shell hooks 上游审阅报告 · 2026-10-13

## 给维护者的结论

本轮 25 个官方文档来源全部报 changed，逐页去标签正文比对后只有 `docs/hooks`（Lifecycle hooks）有实质改动，其余 24 页正文逐行相同，差异只在站点构建指纹；`docs/chat` 另有一处交互快捷键改动，按父进程冻结的范围排除。

**Lifecycle hooks 的 hook stdin 载荷被整体改写**：`event` 字段被删除，改由公共字段 `session_id` + `cwd` + `hook_event_name` 表达事件身份，并按事件新增专属字段——`SessionStart` 增 `source`（`startup | resume | compact`），`UserPromptSubmit` 保留 `prompt`，`PreToolUse` 把 `tool`/`input` 改名为 `tool_name`/`tool_input` 并新增 `tool_use_id`，`PostToolUse` 再加 `tool_response`，`PreCompact` 新增 `trigger` 与 `custom_instructions`，`PostCompact` 新增 `trigger` 与 `compact_summary`，`Stop` 新增 `last_assistant_message`。示例中的 session id 由 `ses_01abc123` 换成 32 位十六进制串，官方“Block a matched tool”示例也从读 `input` 改为读 `tool_input`。这推翻了已发布的载荷字段清单，`hooks.input` 与 `hooks.diagnostics` 升到新章节版本 `bob-cli-hooks-v2`。

**事件名单本身没变。** Supported hooks 表格、Hook reference 目录、Exit codes and blocking 表、Command details、Current limitations、Configuration 与 Hook schema 段落与基线逐行相同，七个第一方事件及其触发时点、可否阻断、stdout 处理都不受影响，`hooks.events` 的答案保持 `answered`，只补一句说明差异只在载荷。
