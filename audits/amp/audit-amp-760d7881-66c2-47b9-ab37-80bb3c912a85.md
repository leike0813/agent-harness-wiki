还有一个需要维护者决定的问题：`source-amp-manual` 登记的 `https://ampcode.com/manual` 会重定向到 HTML 页面，响应里带每次请求生成的 CSP nonce，同一分钟抓三次得到三个不同 sha256。它的 hash 变化不是内容证据，本轮按引用逐字比对判定无内容变化，但这意味着它会在此后每轮继续报 changed。

## 变化的意义与证据边界

### Model Routing 的 connection 由三种变四种，并新增 Painter 一节

`Connections` 一节现在写「There are four kinds」，在 API key、订阅之后新增 **Cloud platforms**（Amazon Bedrock、Google Cloud Agent Platform/Vertex）与原已存在的 gateway 类并列成四条；订阅一条补了「用 ChatGPT 登录同时也登录 Amp，一个 ChatGPT 账户只能连一个 Amp 账户，多 Amp 账户场景改选 Connect Through Codex」。同页还多了一整节 **Painter**：账号启用 Google Painter 后可把图像模型从 Amp (Default) 换成 Gemini 3.1 Flash Image (Nano Banana 2)，需要启用的 Google AI Studio API key connection，最终由哪条 connection 服务仍按顺序与 model mapping 决定。对应引用为 `ref-amp-routing-connections-kinds`、`ref-amp-routing-connections-platforms`、`ref-amp-routing-enterprise-connections`、`ref-amp-routing-check-access`、`ref-amp-routing-painter` 与 `ref-amp-routing-painter-routing`，都绑定 2026-10-03 快照。

这些结论只到来源级：文档描述了设置与命令，没有说明 Painter 在 CLI 侧是否有对应入口，也没有给出图像模型失败后的重试行为。`providers.models` 仍是 answered，`providers.responses` 仍是 partial。

### ChatGPT 订阅的登录方式换了说法，也多了 CLI 入口

`/docs/the-dial` 的 `Use a ChatGPT Subscription` 从「link a ChatGPT subscription」改成「sign in with ChatGPT 并允许 token sharing」，并新增 CLI 入口 `amp config model-providers add-chatgpt-subscription`（简写 `amp add-chatgpt-sub`），说明旧版 ChatGPT connection 继续可用；另外写明 2026-09-28 之前登录的订阅已自动保存 ChatGPT Only preset 的 pin，停用或删除订阅时 Amp 会提示把角色退回 Auto。对应引用为 `ref-amp-dial-chatgpt-signin`、`ref-amp-dial-chatgpt-preset` 与 `ref-amp-dial-chatgpt-pins`。

同页还写明 Tune Modes 固定主 agent、Oracle 与子代理都改不了 image generation 这类 supporting system model（`ref-amp-dial-system-models`），这与新出的 Painter 事实互为边界，已一并写进 `providers-models`。

### 其余页面的变化止于渲染样板

`cli`、`cli/settings`、`cli/keybindings`、`cli/streaming-json`、`cli/runners`、`customize/plugins`、`plugin-api` 七页被引用的小节正文未变：把当前响应的既有引用摘录去标签、归一空白后逐字比对，68 条引用里 65 条命中，其余三条分别是上面两页的正文改动和 `ref-amp-manual-intro` 的渲染差异。插件页新增的 4 个示例插件（BTW、Turn Stats、`/goal`、Kitchen Sink）与「Amp 自带写插件的内置 skill」一句属于示例补充，不改变任何固定问题的答案。
