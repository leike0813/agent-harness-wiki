## 语义 triage

### 纳入：skills

`src/services/skills/SkillsManager.ts`（+480 / −46）。真实变化：

- `scanSkillsDirectory` 把条目分成 `directSkills` 与 `containerPaths`：含 `SKILL.md` 的是直接技能，其余**符号链接**被当作「技能容器」交给 `scanSkillContainer`，只下钻一层（194-212、228-268）。
- 容器内技能进入 `containerSkillPaths`，`assertNotContainerSkill` 让 `deleteSkill` / `moveSkill` / `updateSkillModes` 对它们直接抛 `skills:errors.container_skill_read_only`（757-767）。
- `isHiddenEntry` 使 `.` 前缀条目在扫描与监视中都被跳过（52-59）。
- `discoverSkills` 改为经 `discoveryQueue` 串行，`runDiscovery` 写入一份新的 `DiscoveryPass`，结束后由 `publishSkills` 整体发布；非 `ENOENT`/`ENOTDIR` 的错误把路径记入 `failedPaths`，其下已发现的技能保留到下次（94-99、101-121、139-150）。

- `SKILLS_WATCH_PATTERN` 由 `**/SKILL.md` 改为 `{*,*/SKILL.md}`；`syncContainerWatchers` 按容器真实路径补挂/注销监视器（1100-1118、1124-1133）。
