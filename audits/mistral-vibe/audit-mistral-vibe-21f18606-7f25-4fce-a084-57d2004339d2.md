# mistral-vibe 文档来源窄化复核（audit-mistral-vibe-21f18606）

## 结论

本轮把 scanner 判定的「六个主题全部受影响」收窄为**两个主题、三道固定问题**，并据此新建两章 edition。
其余被 scanner 牵连的主题经逐条核对后确认**当前归档文本仍支持已发布陈述**，未改动正文。

## 关键限制：五页基线均不可 diff

scanner 报告五个官方文档页 `status: changed`，但**这五页的上一版基线原文都不在项目 `archive/` 树里**
（`archive/mistral-vibe/` 下只有本轮新归档的五个 `artifact-source-*/source.md`）。因此无法做文本 diff。

本轮全部结论的强度是「**当前归档文本仍支持 / 不再支持已发布陈述**」，**弱于**「已验证的语义增量」。
既不能断言上游新增了某段内容，也不能断言上游删除了某段内容。`investigation_notes` 已就此明确记录。

## 受影响并已修订（narrow_investigation → 2 topics）

### custom_agents → 新建 `mistral-vibe-cli-custom_agents-v3`

证据：`archive/mistral-vibe/artifact-source-mistral-vibe-docs-agents-087fa322eb4f/source.md`

1. **内置 agent 表（`agents-entry` / `agents.roles`）**：当前页把 `smart-approve` 列进内置可选集合
   （`default`、`plan`、`accept-edits`、`smart-approve`、`auto-approve`、`lean`，共六个，外加内置
   subagent `explore`）。已发布 `custom_agents-v2` 只记了五个，漏了 `smart-approve`。同一页还给
   `auto-approve` 加了"仅在受信任沙箱环境使用，否则可对任意可达路径执行 `rm -rf`"的警告。
2. **启动开关（`agents-invocation` / `agents.invocation`）**：当前页"Select an agent"一节只有
   `--agent`、`Shift+Tab`、`default_agent` 三条路径，**没有** `--auto-approve` / `--yolo`；
   `yolo` 仅作为 agent 文件 `safety` 字段取值出现。已发布 v2 却把这两个开关按"官方文档补充"引用。
   该开关组合在本主题固定来源里没有文档支撑。

其余陈述仍被当前页原样支持，未动：自定义 agent 位置、两种 `agent_type`、`safety` 仅改边框颜色、
custom subagents 的 text-only 结果与不能向用户提问、`agents-format` 的字段表。
